TRADUCTOR

Traductor Interactivo con Deep Translator

💡 ¿Qué es Deep Translator?

Deep Translator es una biblioteca de Python que facilita la traducción de textos entre múltiples idiomas utilizando diferentes servicios de traducción como Google Translate, Microsoft Translator, DeepL, entre otros. Es una herramienta versátil que simplifica la integración de capacidades de traducción en aplicaciones Python, permitiendo traducir texto, documentos y detectar idiomas de forma automática.

📝 Código del Ejemplo

traductor.py 
                    # -*- coding: utf-8 -*-
# Instalar librería antes de ejecutar:
# pip install deep-translator keyboard

from deep_translator import GoogleTranslator
import keyboard

def traducir(texto, idioma_destino):
    """Traduce un texto del español al idioma elegido"""
    traduccion = GoogleTranslator(source='es', target=idioma_destino).translate(texto)
    return traduccion

def main():
    print("=== 🌍 Traductor interactivo desde español ===")
    print("Presiona:")
    print("  A → Traducir al inglés")
    print("  X → Traducir al alemán")
    print("  Y → Traducir al francés")
    print("  Q → Salir del programa")

    while True:
        texto = input("\nEscribe un texto en español: ")

        print("\nAhora presiona una tecla:")
        print("A (inglés) | X (alemán) | Y (francés) | Q (salir)")

        while True:
            if keyboard.is_pressed('a'):
                print("\n🔠 Traducción al inglés:")
                print(traducir(texto, 'en'))
                break
            elif keyboard.is_pressed('x'):
                print("\n🇩🇪 Traducción al alemán:")
                print(traducir(texto, 'de'))
                break
            elif keyboard.is_pressed('y'):
                print("\n🇫🇷 Traducción al francés:")
                print(traducir(texto, 'fr'))
                break
            elif keyboard.is_pressed('q'):
                print("\n👋 Saliendo del traductor...")
                return

if __name__ == "__main__":
    main()

📚 Glosario de Funciones

🌐 GoogleTranslator

Clase de deep-translator que utiliza la API de Google Translate. Permite traducir textos entre más de 100 idiomas de forma gratuita. Requiere especificar el idioma origen (source) y el idioma destino (target).

Sintaxis: GoogleTranslator(source='es', target='en')

🔄 translate()

Método que realiza la traducción del texto. Recibe como parámetro el texto a traducir y retorna la traducción en el idioma especificado. Se encadena después de crear el objeto GoogleTranslator.

Uso: traductor.translate(texto)

⌨️ keyboard.is_pressed()

Función del módulo keyboard que detecta si una tecla específica está siendo presionada en tiempo real. Retorna True si la tecla está presionada, False en caso contrario.

Sintaxis: keyboard.is_pressed('tecla')

📝 input()

Función de Python que solicita entrada de texto al usuario. Pausa la ejecución del programa hasta que el usuario escribe algo y presiona Enter. Retorna el texto ingresado como string.

Sintaxis: input("mensaje")

🔧 def función()

Define una función personalizada en Python. Permite encapsular código reutilizable. En este programa se definen traducir() para traducir y main() para ejecutar el programa principal.

Sintaxis: def nombre_funcion(parametros):

↩️ return

Palabra clave que devuelve un valor desde una función y finaliza su ejecución. En traducir() retorna el texto traducido. En main() termina el programa cuando se presiona 'q'.

Uso: return valor

🔄 while True

Crea un bucle infinito que se ejecuta continuamente. Se usa dos veces: uno para mantener el programa activo aceptando textos, otro para esperar que el usuario presione una tecla.

Control: Se detiene con break o return

❓ if/elif/else

Estructuras condicionales que permiten ejecutar código diferente según la condición. if evalúa la primera condición, elif evalúa alternativas, else se ejecuta si ninguna es verdadera.

Uso: Determina qué idioma traducir según la tecla presionada

🛑 break

Termina inmediatamente el bucle más cercano. Se usa después de cada traducción para salir del bucle de detección de teclas y permitir al usuario ingresar un nuevo texto.

Efecto: Sale del while True interno

📦 from ... import

Importa elementos específicos de un módulo. Permite usar GoogleTranslator directamente sin escribir deep_translator.GoogleTranslator.

Sintaxis: from modulo import clase

🎯 if __name__ == "__main__"

Verifica si el script está siendo ejecutado directamente (no importado como módulo). Es una práctica común en Python para ejecutar código solo cuando el archivo se ejecuta directamente.

Función: Punto de entrada del programa

🌍 Códigos de Idioma

Abreviaturas estándar ISO 639-1 para identificar idiomas. En el código: 'es' = español, 'en' = inglés, 'de' = alemán (Deutsch), 'fr' = francés. Deep Translator soporta más de 100 códigos de idioma.

Ejemplos: 'es', 'en', 'de', 'fr', 'it', 'pt', 'ja', 'zh'
