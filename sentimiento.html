CHAT SENTIMIENTO

Chatbot con Análisis de Sentimientos usando TextBlob

💡 ¿Qué es el Análisis de Sentimientos?

El análisis de sentimientos (también llamado minería de opinión) es una técnica de procesamiento de lenguaje natural que identifica y clasifica las emociones expresadas en un texto. Este chatbot combina TextBlob para análisis de sentimientos y Deep-Translator para traducción, permitiendo detectar si un mensaje es positivo, negativo o neutral. La polaridad se mide en una escala de -1 (muy negativo) a +1 (muy positivo).

📦 Instalación de Librerías

Antes de ejecutar el programa, instala:

pip install textblob deep-translator

📊 Escala de Polaridad de Sentimientos

-1.0 Muy Negativo
-0.2 Negativo
0.0 Neutral
+0.2 Positivo
+1.0 Muy Positivo

🎭 Tipos de Respuestas

😄

Sentimiento Positivo

Polaridad > 0.2

"Me alegra que estés feliz!"

😢

Sentimiento Negativo

Polaridad < -0.2

"Lamento que estés triste"

😐

Sentimiento Neutral

-0.2 ≤ Polaridad ≤ 0.2

"Entiendo"

📝 Código del Ejemplo

chat_sentimiento.py 
                    # Chatbot con análisis de sentimientos usando TextBlob y Deep-Translator
import random
from textblob import TextBlob
from deep_translator import GoogleTranslator

# Inicializar traductor
traductor = GoogleTranslator(source='es', target='en')

# LISTAS DE SALUDOS Y RESPUESTAS
saludos = ["hola", "que tal", "buenos dias", "buenas tardes", "buen dia"]
respuesta_saludos = ["hola como estas?", "como puedo ayudarte?", "hola como te va", "que hay?"]
despedida = ["adios", "bye", "gracias", "nos vemos", "hasta luego", "salir"]
respuesta_despedida = ["adios", "hasta pronto", "fue un placer ayudarte", "cuidate", "nos vemos luego", "bye"]

# LISTAS PARA ANÁLISIS DE SENTIMIENTOS
pregunta_sentimiento = ["como estas", "como te sientes", "que tal estas", "como andas"]
respuesta_feliz = ["Me alegra que estes feliz!", "Que bueno que te sientas bien!", "Genial! Sigue asi!",
                   "Excelente que estes contento!"]
respuesta_triste = ["Lamento que estes triste", "Animo, todo mejora!", "Entiendo como te sientes",
                    "Espero que te sientas mejor pronto"]
respuesta_neutral = ["Entiendo", "Ok, gracias por compartir", "Comprendo como te sientes"]

# Mensaje de bienvenida del chatbot
print("Hola soy Chato, tu Chatbot de confianza, si deseas terminar escribe 'salir'")

while True:
    usuario = input("Tu: ").lower().strip()

    if usuario in saludos:
        print("Chatbot:", random.choice(respuesta_saludos))

    elif usuario in pregunta_sentimiento:
        print("Chatbot: Cuentame, ¿como te sientes? (feliz o triste)")

    elif usuario in despedida:
        print("Chatbot:", random.choice(respuesta_despedida))
        break

    else:
        # Analizar sentimiento con TextBlob y Deep-Translator
        # Traducir al inglés
        texto_ingles = traductor.translate(usuario)

        # Analizar sentimiento
        analisis = TextBlob(texto_ingles)
        polaridad = analisis.sentiment.polarity

        print(f"Chatbot: [Analizando sentimiento... Polaridad: {polaridad:.2f}]")

        # Responder según el sentimiento
        if polaridad > 0.2:
            print("Chatbot:", random.choice(respuesta_feliz))
        elif polaridad < -0.2:
            print("Chatbot:", random.choice(respuesta_triste))
        else:
            print("Chatbot:", random.choice(respuesta_neutral))

📚 Glosario de Funciones

📊 TextBlob

Biblioteca de Python para procesamiento de texto que proporciona análisis de sentimientos, clasificación, traducción, análisis de partes del discurso, extracción de frases nominales y más. Simplifica tareas complejas de PLN con una API intuitiva.

Sintaxis: from textblob import TextBlob

😊 sentiment.polarity

Propiedad que devuelve la polaridad del sentimiento en una escala de -1 a +1. Valores negativos indican sentimiento negativo, valores positivos indican sentimiento positivo, y valores cercanos a 0 indican neutralidad.

Escala: -1.0 (negativo) → 0.0 (neutral) → +1.0 (positivo)

🌐 GoogleTranslator

Clase de deep-translator que traduce texto usando Google Translate. En este caso se inicializa para traducir del español ('es') al inglés ('en'), ya que TextBlob funciona mejor con texto en inglés.

Configuración: GoogleTranslator(source='es', target='en')

🔄 translate()

Método que realiza la traducción del texto español al inglés. Necesario porque TextBlob analiza sentimientos con mayor precisión en inglés.

Uso: traductor.translate(texto)

🎲 random.choice()

Selecciona aleatoriamente una respuesta de las listas, haciendo que el chatbot parezca más natural y menos repetitivo al variar sus respuestas.

Retorna: Un elemento aleatorio de la lista

⚠️ try/except

Estructura de manejo de errores. El bloque try intenta ejecutar el análisis de sentimientos. Si ocurre algún error (red, traducción, análisis), el except lo captura y muestra un mensaje amigable.

Función: Previene que el programa se detenga por errores

🔍 Operador in

Verifica si la entrada del usuario está en las listas predefinidas (saludos, preguntas sobre sentimientos, o despedidas).

Retorna: True si está en la lista, False si no

📝 input()

Captura la entrada del usuario. El texto ingresado es procesado con lower() y strip() antes de analizarse.

Sintaxis: input("mensaje")

⬇️ lower()

Convierte el texto a minúsculas para normalizar la entrada y facilitar las comparaciones con las listas predefinidas.

Ejemplo: "HOLA" → "hola"

✂️ strip()

Elimina espacios en blanco al inicio y final del texto ingresado por el usuario, limpiando la entrada de espacios accidentales.

Ejemplo: " hola " → "hola"

🔄 while True

Bucle infinito que mantiene el chatbot ejecutándose continuamente hasta que el usuario escribe una palabra de despedida y se ejecuta break.

Función: Mantiene la conversación activa

❓ if/elif/else

Estructura condicional que determina cómo responder. Primero verifica saludos y despedidas. Si no coincide con patrones conocidos, el else activa el análisis de sentimientos.

Función: Lógica de decisión del chatbot

🛑 break

Termina el bucle while True cuando el usuario escribe una palabra de despedida, finalizando la conversación.

Efecto: Cierra el programa

📊 f-strings

Formato de cadenas que permite insertar variables dentro de strings. Se usa para mostrar la polaridad del sentimiento con formato de 2 decimales.

Ejemplo: f"Polaridad: {polaridad:.2f}"

🖨️ print()

Muestra mensajes del chatbot en consola: bienvenida, respuestas, polaridad analizada, y mensajes de error si algo falla.

Función: Comunicación con el usuario
