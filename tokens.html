💡 ¿Qué son los Tokens?

Token se refiere a la descomposición de un texto (oración, frase, archivo de texto) con el objetivo de poder analizar el lenguaje escrito. Por ejemplo: contar palabras, contar longitud de las palabras, descubrir el sentimiento plasmado en el texto, traducirlo, etc.

📚 Glosario de Funciones

🔄 replace()

Reemplaza todas las ocurrencias de un carácter o cadena por otro. Se utiliza para eliminar signos de puntuación o caracteres no deseados.

Sintaxis: texto.replace(viejo, nuevo)

⬇️ lower()

Convierte todo el texto a minúsculas. Esto es útil para normalizar el texto y hacer comparaciones sin distinguir entre mayúsculas y minúsculas.

Sintaxis: texto.lower()

✂️ split()

Divide un texto en una lista de palabras utilizando un separador (por defecto, espacios). Cada palabra se convierte en un elemento independiente de la lista.

Sintaxis: texto.split(separador)

📏 len()

Retorna la longitud de un objeto. En el caso de listas, devuelve el número de elementos. Se utiliza para contar cuántos tokens (palabras) hay en el texto.

Sintaxis: len(objeto)

🖨️ print()

Muestra información en la consola. Es fundamental para visualizar los resultados del procesamiento de texto y verificar cada paso del análisis.

Sintaxis: print(valor1, valor2, ...)

📋 Listas

Estructura de datos que almacena múltiples elementos en orden. Los tokens se almacenan en una lista, donde cada palabra es un elemento accesible por su índice.

Ejemplo: ['hola', 'mundo', 'python']
