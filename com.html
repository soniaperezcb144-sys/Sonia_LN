Chatbot Educativo de Componentes Arduino

💡 ¿Qué es este Chatbot?

Este chatbot educativo está diseñado para ayudarte a aprender sobre los componentes de Arduino. Utiliza un diccionario para almacenar 26 componentes diferentes con sus definiciones. El usuario puede preguntar sobre cualquier componente escribiendo su nombre, y el chatbot responderá con una explicación clara. Si el componente no existe o está mal escrito, el chatbot solicitará que se escriba correctamente. Es una herramienta perfecta para estudiantes y principiantes en electrónica y robótica.

📝 Código del Ejemplo

chat_componentes.py 
  # Chatbot con análisis de sentimientos usando TextBlob y Deep-Translator
import random
from textblob import TextBlob
from deep_translator import GoogleTranslator

# Inicializar traductor
traductor = GoogleTranslator(source='es', target='en')

# LISTAS DE SALUDOS Y RESPUESTAS
saludos = ["hola", "que tal", "buenos dias", "buenas tardes", "buen dia"]
respuesta_saludos = ["hola como estas?", "como puedo ayudarte?", "hola como te va", "que hay?"]
despedida = ["adios", "bye", "gracias", "nos vemos", "hasta luego", "salir"]
respuesta_despedida = ["adios", "hasta pronto", "fue un placer ayudarte", "cuidate", "nos vemos luego", "bye"]

# LISTAS PARA ANÁLISIS DE SENTIMIENTOS
pregunta_sentimiento = ["como estas", "como te sientes", "que tal estas", "como andas"]
respuesta_feliz = ["Me alegra que estes feliz!", "Que bueno que te sientas bien!", "Genial! Sigue asi!",
                   "Excelente que estes contento!"]
respuesta_triste = ["Lamento que estes triste", "Animo, todo mejora!", "Entiendo como te sientes",
                    "Espero que te sientas mejor pronto"]
respuesta_neutral = ["Entiendo", "Ok, gracias por compartir", "Comprendo como te sientes"]

# Mensaje de bienvenida del chatbot
print("Hola soy Chato, tu Chatbot de confianza, si deseas terminar escribe 'salir'")

while True:
    usuario = input("Tu: ").lower().strip()

    if usuario in saludos:
        print("Chatbot:", random.choice(respuesta_saludos))

    elif usuario in pregunta_sentimiento:
        print("Chatbot: Cuentame, ¿como te sientes? (feliz o triste)")

    elif usuario in despedida:
        print("Chatbot:", random.choice(respuesta_despedida))
        break

    else:
        # Analizar sentimiento con TextBlob y Deep-Translator
        # Traducir al inglés
        texto_ingles = traductor.translate(usuario)

        # Analizar sentimiento
        analisis = TextBlob(texto_ingles)
        polaridad = analisis.sentiment.polarity

        print(f"Chatbot: [Analizando sentimiento... Polaridad: {polaridad:.2f}]")

        # Responder según el sentimiento
        if polaridad > 0.2:
            print("Chatbot:", random.choice(respuesta_feliz))
        elif polaridad < -0.2:
            print("Chatbot:", random.choice(respuesta_triste))
        else:
            print("Chatbot:", random.choice(respuesta_neutral))

📚 Glosario de Funciones

📖 Diccionarios {}

Estructura de datos que almacena pares clave-valor. En este chatbot, la clave es el nombre del componente y el valor es su definición. Permite búsquedas rápidas y eficientes.

Sintaxis: {"clave": "valor"}
Ejemplo: {"protoboard": "Es una placa..."}

📝 input()

Captura la entrada del usuario desde el teclado. En este programa, solicita el nombre del componente sobre el que se desea aprender. Retorna el texto como string.

Sintaxis: input("mensaje")

⬇️ lower()

Convierte todo el texto a minúsculas. Asegura que el chatbot reconozca "Protoboard", "PROTOBOARD" y "protoboard" como la misma entrada, mejorando la flexibilidad.

Ejemplo: "MOTOR DC" → "motor dc"

🔍 Operador in

Verifica si una clave existe dentro del diccionario. Retorna True si el componente está en el diccionario, False si no existe. Permite validar la entrada del usuario.

Sintaxis: if componente in diccionario:

🔄 Bucle for

Itera sobre cada elemento del diccionario. Se usa para imprimir la lista completa de componentes disponibles al inicio del programa, mostrando todas las opciones al usuario.

Sintaxis: for item in diccionario:

♾️ while True

Crea un bucle infinito que mantiene el chatbot ejecutándose continuamente. Solo se detiene cuando el usuario escribe "salir" y se ejecuta el comando break.

Función: Mantiene la conversación activa

❓ if/else

Estructura condicional que determina qué hacer según la entrada. Primero verifica si es "salir", luego si el componente existe en el diccionario, y finalmente muestra un error si no se encuentra.

Función: Lógica de decisión del chatbot

🛑 break

Termina inmediatamente el bucle while True. Se ejecuta cuando el usuario escribe "salir", finalizando el programa y cerrando el chatbot.

Efecto: Sale del bucle y cierra el programa

🖨️ print()

Muestra mensajes en la consola. Se usa para: mensaje de bienvenida, listar componentes, mostrar definiciones y mensajes de error o despedida.

Sintaxis: print("mensaje")

🔑 Acceso a Diccionario

Obtiene el valor asociado a una clave usando corchetes. En este caso, recupera la definición del componente solicitado usando el nombre como clave.

Sintaxis: diccionario[clave]
Ejemplo: componentes["protoboard"]

📋 Strings Multilínea

Cadenas de texto que ocupan múltiples líneas usando concatenación o comillas triples. Se usan para definiciones largas de componentes que no caben en una sola línea.

Ejemplo: "texto parte 1 " "texto parte 2"

🔤 Comparación de Strings

Compara cadenas de texto para verificar si son exactamente iguales. Se usa para detectar si el usuario escribió "salir" y para buscar componentes en el diccionario.

Sintaxis: if texto == "salir":
