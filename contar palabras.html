CONTAR PALABRAS

Análisis de Frecuencia en Textos

💡 ¿Para qué contar palabras?

El conteo de palabras es fundamental en el procesamiento de lenguaje natural. Permite analizar la frecuencia con la que aparecen términos específicos en un texto, identificar palabras clave, detectar patrones lingüísticos y realizar análisis estadísticos del lenguaje. Esta técnica es la base para muchas aplicaciones como análisis de sentimientos, clasificación de textos y detección de temas.

🎯 Proceso Paso a Paso

1

Limpiar el texto

Convertir a minúsculas y eliminar signos de puntuación para normalizar el texto.

2

Tokenización

Dividir el texto en palabras individuales (tokens) utilizando espacios como separadores.

3

Contar palabras

Usar un diccionario para almacenar cada palabra y su frecuencia de aparición.

4

Mostrar resultados

Presentar el diccionario con todas las palabras y sus respectivos conteos.

📝 Código del Ejemplo

contar_palabras.py 
                    #frase ejemplo
frase= "python es divertido y python poderoso "

#1.-limpiar el texto (minuscula y sin puntuacion)
frase_limpia= frase.replace(".","").replace(".","").lower()

#2.- Dividir en palabras (tokenizacion)
tokens=frase_limpia.split()
#3.- contar palabras usando diccionario
frecuencia={}
for palabra in tokens:
    if palabra in frecuencia:
        frecuencia[palabra]+=1
    else:
        frecuencia[palabra]=1

#4.-mostrar resultados
print(frecuencia)

📚 Glosario de Funciones y Conceptos

📖 Diccionarios {}

Estructura de datos que almacena pares clave-valor. En este caso, la clave es la palabra y el valor es su frecuencia. Permite búsquedas y actualizaciones rápidas.

Ejemplo: {'python': 2, 'es': 1}

🔄 Bucle for

Estructura de control que itera sobre cada elemento de una secuencia. En este código, recorre cada palabra de la lista de tokens para contarla.

Sintaxis: for item in lista:

❓ Condicional if

Evalúa si una condición es verdadera. Aquí verifica si una palabra ya existe en el diccionario antes de incrementar su contador o agregarla.

Sintaxis: if condición: ... else: ...

➕ Operador +=

Operador de incremento que suma un valor a una variable y guarda el resultado en la misma variable. Se usa para incrementar el contador de frecuencia.

Ejemplo: contador += 1 es igual a contador = contador + 1

🔍 Operador in

Verifica si un elemento existe dentro de una colección (lista, diccionario, string, etc.). Retorna True si el elemento está presente, False si no lo está.

Uso: if palabra in diccionario:

✂️ split()

Divide un string en una lista de palabras usando un delimitador (por defecto, espacios). Es esencial para la tokenización del texto.

Sintaxis: texto.split()

⬇️ lower()

Convierte todo el texto a minúsculas. Asegura que "Python" y "python" se cuenten como la misma palabra, evitando duplicados por diferencias de capitalización.

Sintaxis: texto.lower()

🔄 replace()

Reemplaza todas las ocurrencias de un carácter o subcadena por otro. Se usa para limpiar el texto eliminando puntuación.

Sintaxis: texto.replace(viejo, nuevo)

🖨️ print()

Muestra información en la consola. Imprime el diccionario completo con las frecuencias de cada palabra encontrada en el texto.

Sintaxis: print(variable)
