Glosario de Funciones

if ... else Estructura
Estructura de control condicional que permite ejecutar diferentes bloques de código según si una condición es verdadera o falsa. Si la condición del 'if' se cumple, ejecuta su bloque; de lo contrario, ejecuta el bloque 'else'.
.lower() Método de string
Método que convierte todos los caracteres alfabéticos de una cadena a minúsculas. Es especialmente útil para realizar comparaciones sin distinguir entre mayúsculas y minúsculas, asegurando búsquedas más flexibles.
in Operador
Operador de pertenencia que verifica si un valor está contenido dentro de una secuencia (cadena, lista, tupla, etc.). Devuelve True si el elemento se encuentra presente, False si no existe.
print() Función built-in
Función integrada de Python que imprime información en la salida estándar (consola). Puede recibir múltiples argumentos y los muestra de forma legible para el usuario.
Variables de Texto Concepto
Las variables 'frase' y 'buscada' almacenan cadenas de texto (strings). En este ejemplo, se utilizan para realizar una búsqueda dentro de un texto, comparando si una palabra específica existe dentro de una frase completa.
