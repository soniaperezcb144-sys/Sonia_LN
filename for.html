Glosario de Funciones

for ... in ... Estructura
Estructura de control que permite iterar sobre elementos de una secuencia (lista, cadena, tupla, etc.). Ejecuta un bloque de código para cada elemento de la colección.
print() Función built-in
Función integrada de Python que imprime el contenido en la consola. Puede recibir múltiples argumentos separados por comas.
.split() Método de string
Método que divide una cadena de texto en una lista de palabras (tokens). Por defecto, utiliza espacios en blanco como separador.
import Palabra clave
Palabra clave utilizada para importar módulos o funciones específicas de otros archivos Python. Permite reutilizar código de diferentes módulos.
texto_Limpio Función personalizada
Función importada del módulo 'tokens' que se utiliza para limpiar y procesar texto, preparándolo para análisis de lenguaje natural.
