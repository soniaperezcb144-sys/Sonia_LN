Clasificador de Sentimientos con Python
   '''
crear una frase larga con palabras repetidas donde exprese un sentimiento positivo
y sentimientos negativos, analizar la frase completa, eliminando signos de puntuacion
, tokenizando la frase, y recoriendo la frase con if contabilizar cuantas
palabras positivas y cuants negativas se encontraron, y de ahi determinar
si la frase es positiva o negativa
'''

#creando listas con palabras para detectar el sentir de la frase
palabraspositivas=['feliz','contento','maravillosa','bonito','bonita','color']
palabrasnegativas=['triste','solo','aburrido','malo','deprimido','horrible','muerto','demonios']

frase="solo, triste feliz bonito color"

texto_limpio=frase.replace(",","").replace(".","").lower()
palabras = texto_limpio.lower().split()
verificadas=[]
positivos=0
negativos=0

for palabra in palabras:
    if palabra  in palabraspositivas:
        positivos += 1
    if palabra in palabrasnegativas:
        negativos +=1

print("palabras positivos;",positivos)
print("palabras negativas:",negativos)

for palabra in palabras: #python esta dentro de tokens
    if palabra not in verificadas:
        print(palabra,"tiene",len(palabra),"letras")
        verificadas.append(palabra)

if positivos > negativos:
    print("Tu frase es positiva")

elif negativos > positivos:
    print("Tu frase es negativa")

Glosario de Funciones

.replace() Método de string
Método que reemplaza todas las apariciones de un substring por otro en una cadena de texto. En este código se usa encadenado para eliminar comas y puntos, limpiando el texto para su análisis.
.split() Método de string
Método que divide una cadena en una lista de palabras (tokens) usando espacios en blanco como separador por defecto. Es fundamental para el proceso de tokenización en análisis de texto.
.lower() Método de string
Convierte todos los caracteres de una cadena a minúsculas, permitiendo comparaciones uniformes sin importar la capitalización original del texto.
for ... in Estructura
Bucle que itera sobre cada elemento de una secuencia. En este código se usa para recorrer palabras y clasificarlas según su sentimiento, y también para contar la longitud de palabras únicas.
if ... elif Estructura
Estructura condicional que permite evaluar múltiples condiciones. Se utiliza para clasificar palabras por sentimiento y determinar si la frase general es positiva o negativa.
len() Función built-in
Función que retorna la longitud (número de elementos) de un objeto. En este caso se usa para contar la cantidad de caracteres en cada palabra.
.append() Método de lista
Método que agrega un elemento al final de una lista. Se utiliza para llevar registro de las palabras ya verificadas y evitar duplicados en el análisis.
Operadores += Operador
Operador de asignación aumentada que incrementa el valor de una variable. Se usa para contabilizar palabras positivas y negativas encontradas en el texto.
not in Operador
Operador de no pertenencia que verifica si un elemento NO está contenido en una secuencia. Permite identificar palabras únicas que aún no han sido procesadas.
