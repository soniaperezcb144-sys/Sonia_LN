Búsqueda y Comparación de Texto en Python

Código Completo

Búsqueda de Palabras en Frases
    frase= "python es divertido y poderoso"
buscada="python"

if buscada.lower() in frase.lower():
    print("la palabra esta en la frase")
else:
    print("no se encontro la palabra")

Glosario de Funciones

if ... else Estructura
Estructura condicional que permite ejecutar diferentes bloques de código según si una condición es verdadera o falsa. El bloque 'if' se ejecuta si la condición es True, de lo contrario se ejecuta el bloque 'else'.
.lower() Método de string
Método que convierte todos los caracteres de una cadena a minúsculas. Es útil para realizar comparaciones sin distinguir entre mayúsculas y minúsculas (case-insensitive).
in Operador
Operador de pertenencia que verifica si un elemento está contenido dentro de una secuencia (cadena, lista, tupla, etc.). Retorna True si el elemento existe, False en caso contrario.
print() Función built-in
Función integrada de Python que muestra información en la consola. Acepta uno o más argumentos y los imprime como salida estándar.
Variables (frase, buscada) Concepto
Contenedores que almacenan valores en memoria. En este ejemplo, 'frase' contiene el texto donde se realizará la búsqueda y 'buscada' contiene la palabra que se desea encontrar.
