Chatbot Básico con Listas y Respuestas Aleatorias

💡 ¿Qué es un Chatbot con Listas?

Un chatbot basado en listas es un programa conversacional simple que utiliza listas predefinidas de palabras clave y respuestas. El bot compara la entrada del usuario con las listas de patrones (saludos, preguntas, despedidas) y responde con una opción aleatoria de la lista correspondiente. Este enfoque es ideal para aprender los fundamentos de chatbots: reconocimiento de patrones, manejo de entrada de usuario, y generación de respuestas variadas.

🎭 Categorías de Conversación

👋 Saludos

  • "hola"
  • "que tal"
  • "buenos dias"
  • "buenas tardes"
  • "buen dia"

❓ Preguntas

  • "te gustan los pasteles?"
  • "te gustan las galletas?"
  • "te gusta el dulce"

🤖 Sobre el Bot

  • "como te llamas?"
  • "cual es tu nombre"

👋 Despedidas

  • "adios"
  • "bye"
  • "gracias"
  • "nos vemos"
  • "hasta luego"
  • "salir"

📝 Código del Ejemplo

chat_lista.py 
                    #Ejemplo chatbot con listas basico
import random

#lista de saludos y respuesta
saludos=["hola","que tal","buenos dias","buenas tardes","buen dia"]
respuesta_saludos=["hola, como estas?",
                     "como puedo ayudarte",
                     "que hay?"]

despedida=["adios","bye","gracias","nos vemos","hasta luego","salir"]
respuesta_despedida=["adios,hasta pronto",
                     "fue un placer ayudarte",
                     "cuidate",
                     "nos vemos luego",
                     "bye"]

preguntas=["te gustan los pasteles?",
           "te gustan las galletas?",
           "te gusta el dulce"]

respuestas_preguntas=["si son delisiosas",
                      " si son muy buenas ",
                      " si, ya que comer algo dulce sirve para activar las energia"]

pregunta_ia=["como te llamas?","ual es tu nombre","nombre"]
respuesta_ia=["mi nombre es chato",
              "soy chato tu asistente de confianza",
              "que onda bro, yo soy chato",
              "soy chato un gusto en conocerte"]

#mensaje de bienvenida de chatbot
print("Hola soy chato, tu chatbot de confianza,si deseas"
      "terminar escribe 'salir' ")

while True:
    usuario=input("Tu=").lower().strip()

    if usuario in saludos:
        print("chatbot:",random.choice(respuesta_saludos))

    elif usuario in preguntas:
        print("chatbot:",random.choice(respuestas_preguntas))

    elif usuario in pregunta_ia:
        print("chatbot:",random.choice(respuesta_ia))

    elif usuario in despedida:
        print("chatbot:",random.choice(respuesta_despedida))


        break

📚 Glosario de Funciones

🎲 random.choice()

Selecciona aleatoriamente un elemento de una lista. En el chatbot, proporciona respuestas variadas de las listas de respuestas, haciendo la conversación más natural y menos repetitiva.

Sintaxis: random.choice(lista)
Retorna: Un elemento aleatorio de la lista

📦 import random

Importa el módulo random de Python que proporciona funciones para generar números aleatorios y seleccionar elementos aleatorios de colecciones.

Uso: Necesario para usar random.choice()

📋 Listas []

Estructura de datos que almacena múltiples elementos ordenados. El chatbot usa listas para almacenar patrones de entrada (saludos, preguntas) y posibles respuestas.

Ejemplo: saludos = ["hola", "que tal", "buenos dias"]

📝 input()

Captura la entrada del usuario desde el teclado. Pausa la ejecución hasta que el usuario escribe algo y presiona Enter. Retorna el texto como string.

Sintaxis: input("mensaje")

⬇️ lower()

Convierte todo el texto a minúsculas. Permite que el chatbot reconozca "Hola", "HOLA" y "hola" como la misma entrada, mejorando la flexibilidad del reconocimiento.

Sintaxis: texto.lower()

✂️ strip()

Elimina espacios en blanco, tabulaciones y saltos de línea al inicio y final del texto. Limpia la entrada del usuario de espacios accidentales.

Ejemplo: " hola ".strip() → "hola"

🔍 Operador in

Verifica si un elemento existe dentro de una lista. Retorna True si el elemento está presente, False si no. El chatbot lo usa para verificar si la entrada del usuario coincide con algún patrón conocido.

Sintaxis: if elemento in lista:

🔄 while True

Crea un bucle infinito que mantiene el chatbot ejecutándose continuamente, esperando la entrada del usuario. Solo se detiene cuando encuentra una instrucción break.

Función: Mantiene la conversación activa

❓ if/elif

Estructura condicional que evalúa múltiples condiciones. El chatbot usa if para saludos, elif para preguntas, preguntas sobre el bot, y despedidas.

Función: Determina qué tipo de respuesta dar

🛑 break

Termina inmediatamente el bucle while. Se ejecuta cuando el usuario escribe una palabra de despedida, finalizando la conversación y cerrando el programa.

Efecto: Sale del bucle while True

🖨️ print()

Muestra mensajes en la consola. Se usa para el mensaje de bienvenida y para mostrar las respuestas del chatbot al usuario.

Sintaxis: print("mensaje")

🎨 Encadenamiento de Métodos

Técnica que permite aplicar múltiples métodos en secuencia. El código usa .lower().strip() para convertir a minúsculas y luego eliminar espacios en una sola línea.

Ejemplo: input().lower().strip()
