PREPROCESAMIENTO

Limpieza y Tokenización de Textos con NLTK

💡 ¿Qué es el Preprocesamiento?

El preprocesamiento es una fase crucial en el análisis de lenguaje natural que consiste en limpiar y preparar el texto antes de su análisis. Este proceso incluye convertir el texto a minúsculas, eliminar caracteres especiales, quitar espacios innecesarios y tokenizar (dividir en palabras u oraciones). Un buen preprocesamiento mejora significativamente la calidad del análisis posterior, eliminando ruido y estandarizando el formato del texto.

🎯 Pasos del Preprocesamiento

1

Convertir a minúsculas

Normaliza el texto para que "Python" y "python" se traten igual.

2

Eliminar espacios extras

Quita espacios al inicio, final y saltos de línea innecesarios.

3

Eliminar caracteres especiales

Remueve números, símbolos y puntuación usando expresiones regulares.

4

Tokenizar

Divide el texto en palabras u oraciones para su análisis individual.

📝 Código del Ejemplo

preprocesamiento.py 
                    import re
import nltk
#descarga de modelo de tokenizacion
#nltk.download('punkt_tab')
#importamos las funsiones de la libreria
from nltk.tokenize import word_tokenize,sent_tokenize

#ejemplo de texto  a tokenizar
texto=("En la materia de lenguaje natural PNL y vision artificial VA, se desarroolola"
       "un portafolio de practicas con material de apoyo para los siguientes"
       "semestres de la especialidad, incluyendo practicas y glosario de funciones"
       "por cada práctica")

#como buena practica antes de tokenizar, hay que limpiar el texto
#convertir en minuscula
texto_limpio=texto.lower()

#quitar saltos de linea y espacio
texto_limpio=texto_limpio.strip()

#eliminar caracteres que no sean letras
texto_limpio = re.sub(r'[^a-záéíóúüñ\s]', '', texto_limpio)

#TOKENIZAR
#token por palabras
palabras=word_tokenize(texto_limpio,language='spanish')
print("token en palabras",palabras)

#token por oraciones
oraciones=sent_tokenize(texto)
print("token en oraciones:",oraciones)

print("Texto original",texto)
print(texto_limpio)

📚 Glosario de Funciones

📦 import re

Importa el módulo de expresiones regulares (Regular Expressions) de Python. Permite buscar, reemplazar y manipular patrones de texto de forma avanzada y eficiente.

Uso: Esencial para limpieza avanzada de texto

🔤 import nltk

Importa Natural Language Toolkit, una de las bibliotecas más populares de Python para procesamiento de lenguaje natural. Incluye herramientas para tokenización, análisis sintáctico, clasificación y más.

Instalación: pip install nltk

⬇️ lower()

Convierte todo el texto a minúsculas. Es fundamental para normalizar el texto y asegurar que palabras con diferentes capitalizaciones se traten como idénticas.

Sintaxis: texto.lower()

✂️ strip()

Elimina espacios en blanco, tabulaciones y saltos de línea al inicio y final del texto. Limpia el texto de espacios innecesarios que pueden interferir con el análisis.

Sintaxis: texto.strip()

🔍 re.sub()

Sustituye patrones de texto usando expresiones regulares. El patrón r'[^a-záéíóúüñ\s]' indica "todo lo que NO sea letras (incluyendo acentos) ni espacios", reemplazándolo por cadena vacía.

Sintaxis: re.sub(patrón, reemplazo, texto)

📖 word_tokenize()

Función de NLTK que divide un texto en palabras individuales (tokens). Considera reglas lingüísticas específicas del idioma para separar correctamente las palabras.

Sintaxis: word_tokenize(texto, language='spanish')

📝 sent_tokenize()

Función de NLTK que divide un texto en oraciones. Utiliza algoritmos inteligentes para identificar finales de oración considerando puntos, abreviaturas y otros patrones.

Sintaxis: sent_tokenize(texto)

🌍 language='spanish'

Parámetro que especifica el idioma del texto para aplicar reglas de tokenización específicas. NLTK ajusta su procesamiento según las características del español.

Idiomas: 'spanish', 'english', 'french', etc.

⚙️ Expresiones Regulares

Patrones de búsqueda de texto. El prefijo r indica "raw string" para evitar conflictos con caracteres de escape. Los corchetes [ ] definen conjuntos de caracteres, y ^ niega la selección.

Ejemplo: r'[^a-z]' = "no letras minúsculas"

📥 from ... import

Importa funciones específicas de un módulo, permitiendo usarlas directamente sin prefijo. En lugar de nltk.tokenize.word_tokenize(), se puede usar solo word_tokenize().

Sintaxis: from modulo import funcion

💾 nltk.download()

Descarga recursos adicionales de NLTK como modelos de tokenización, corpus, y datos de entrenamiento. 'punkt_tab' es el modelo necesario para tokenización por palabras y oraciones.

Sintaxis: nltk.download('punkt_tab')

🖨️ print()

Muestra información en la consola. Permite visualizar el texto original, el texto limpio y los resultados de la tokenización para verificar cada paso del preprocesamiento.

Sintaxis: print(variable)
